# 职官数据结构化定义

## 2026/01/17 版本

分为文献资料，职官表两部分；
文献数据记录原始资料数字化结果；职官表为最终结果呈现；

当前的文献数据，来自《宋代官制辞典》数字化结果，组织方式如下：
  * ID
  * 条目名称
  * 字段，字段文本
  * 原书索引
    * 分类（目录）
    * 页码

职官表中包含机构与官职两大类，每类再进行细分：
机构
  * ID
  * 类别：官司，官署，部门等
  * 条目名
  * 别称
  * 上级，下级机构
  * 编制信息
  * 始置时间，罢置时间
  * (其余信息)：如衙署等

职官
  * ID
  * 类别：官职，吏职，军职等
  * 条目名
  * 别称
  * 隶属机构
  * 始置时间，罢置时间
  * (其余信息)：如官品，职能，机构内序位等

### 从文献到职官表

文献条目虽然与职官表条目理论上一致，但是职官表信息并非完全来源于对应的文献条目，也可能来自相关的文献条目；
因此，从一条文献条目，往往提取出一组职官条目信息（不一定是当前职官的信息）；

同时记录结论的证据（溯源信息）
  * 原始信息
  * 文本引用信息

例如，文献条目提取出来的信息结构（可能）如下
  * 条目名称
  * 属性名称，属性值（结论）
  * 溯源信息
举例：
  * 尚书省左司
  * 类别：官司名
  * 溯源信息
    * 原始信息："官司名"
    * 引用信息：《宋代官制辞典》198页，‘尚书省左司’条目，‘说明文本’字段。
举例2：
  * 相关条目：尚书省左司，吏房
  * 类别：上下级机构关系
  * 溯源信息
    * 原始信息："左司掌治尚书省更房、户房、礼房、奏钞房、班簿房。"
    * 引用信息：《宋代官制辞典》198页，‘尚书省左司’条目，‘执掌’字段。

通过收集各方面的提取信息，汇总为最终的职官表。
