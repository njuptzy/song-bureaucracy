# v2 层级关系使用逻辑

本文只说明当前层级关系页面怎么使用、各区域显示什么，不涉及代码实现。

## 1. 层级页面展示什么

层级页面用于查看机构和官职之间的组织关系，中央树显示三类关系：

| 关系 | 显示含义 |
| --- | --- |
| 上下级机构 | 上级机构下面有哪些下级机构 |
| 编制隶属 | 某个机构下面有哪些官职 |
| 统称与实例 | 一个统称下面有哪些具体实例 |

“前后演变”不画进中央层级树，但会出现在右侧实体详情中。

## 2. 页面区域

- 顶部：当前时间、统计、视图切换和图例。
- 左侧：机构和官职列表。
- 中央：当前选中实体的层级树。
- 右侧：实体详情或关系证据。
- 底部：控制当前查看时间段的年表。

## 3. 两种层级查看方式

### 所选时段结构

默认使用这个模式。中央树只显示与底部所选时间段有关的层级关系。

调整底部年表后，以下内容会一起更新：

- 当前显示的层级关系；
- 左侧有层级和无层级实体的分组；
- 绿色活跃圆点；
- 左侧排序；
- 顶部统计。

### 历时全貌

显示这个实体在整个宋代记录中出现过的全部层级关系，不再只看当前选中的时间段。

在这个模式下，节点旁会显示关系的年份、时间范围或“时间未明”。底部时间仍用于标记当前时段的活跃实体。

## 4. 左侧列表怎么用

左侧列表分为两部分：

- 上半部分：当前查看范围内参与层级关系的实体；
- 分隔线以下：当前查看范围内没有层级关系的实体。

列表优先显示当前时间段内有明确记录的实体，其次按记录数量和名称排序。

- 机构使用方形标记；
- 官职使用圆形标记；
- 绿色圆点表示该实体在当前时间段内有明确纪年记录。

没有绿点不代表实体不存在。它仍可能因为跨年关系或时间未明的关系而显示在树中。

点击左侧词条后，该实体会成为中央树的中心，并打开右侧详情。左侧栏可以收起。

## 5. 中央层级树怎么用

中央树以当前选中的实体为中心，向下展开它的下级机构、属官或具体实例。

子节点按以下顺序排列：

1. 上下级机构；
2. 编制隶属；
3. 统称与实例。

具体操作：

- 点击节点名称：打开或关闭该实体的右侧详情，不改变树中心；
- 点击“以此为中心”：把该节点设为新的树中心；
- 点击三角：展开或收起该节点的下级；
- 点击上方的上级路径：返回某一级并重新展开。

如果一个实体有多个上级，页面会选择一条主要路径显示，其他关系以“另有 N 个上级”提示。主要路径只是浏览路径，不代表其他上级无效。

## 6. 节点和关系怎么看

### 实体形状

| 实体 | 外形 |
| --- | --- |
| 机构 | 方角矩形 |
| 官职 | 圆角胶囊形 |

### 关系提示

| 关系 | 颜色和图标 |
| --- | --- |
| 上下级机构 | 深褐色、建筑图标 |
| 编制隶属 | 橙色虚线、人形图标 |
| 统称与实例 | 灰褐色点线、交叠方框图标 |

当前树中心使用深色底。节点旁还可能显示：

- 关系发生的年份或范围；
- “时间未明”；
- 编制员额；
- “另有 N 个上级”。

## 7. 查看关系证据

子节点右侧的“证”按钮用于查看这条关系的史料依据。

证据栏显示：

- 关系双方和关系类型；
- 关系发生时期；
- 引用出处；
- 引文原文；
- 说明或考证备注。

同一关系如果在多个时期有记录，会按时期分别展示。再次点击“证”或点击关闭按钮可收起证据栏。

## 8. 右侧实体详情

右侧详情显示：

- 实体名称、类型和有记录的时间范围；
- 官职性质、品级等属性；
- 与该实体有关的全部关系；
- 该实体的纪事和引用。

关系文字以当前实体为视角：

| 显示文字 | 含义 |
| --- | --- |
| 下级 / 上级 | 当前实体的下级或上级机构 |
| 属官 / 隶属于 | 当前机构的属官，或当前官职所属机构 |
| 实例 / 统称 | 当前统称的实例，或当前实例所属统称 |
| 后继为 / 前身为 | 当前实体的前后演变 |

右侧详情显示该实体的全部历史关系，不只显示当前时间段。因此右侧可能出现中央树中没有的关系，也可能出现“前后演变”。

## 9. 搜索和关系跳转

顶部搜索框按实体名称查找机构或官职。点击搜索结果后，该实体成为中央树中心，并打开右侧详情。

鼠标移到右侧某条关系上时：

- 左侧对应实体会高亮并滚动到可见位置；
- 如果它已经出现在中央树中，中央节点也会高亮。

点击这条关系后，页面跳到关系另一方，并以它为新的树中心。

## 10. 常见现象

### 没有绿点的实体为什么仍在树中？

绿点只表示当前时间段内有明确纪年记录。该实体可能存在跨年关系或时间未明的层级关系。

### 右侧有关系，中央树里为什么没有？

可能是关系不在当前时间段，属于“前后演变”，或者位于当前树中心的上级或其他路径中。

### 切换时间后，为什么树变了但右侧关系没有完全变化？

中央树显示当前时段的组织结构；右侧详情显示实体的完整历史关系。

### 历时全貌中为什么还有绿色圆点？

历时全貌展示全部层级关系，绿色圆点仍用于提示底部当前时间段内有明确记录的实体。
