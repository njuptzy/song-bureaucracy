# v2 层级关系与时间联动使用逻辑

本文从使用者看到的页面出发，说明当前层级关系画布如何显示、实体目录如何排序、底部年表如何选择时间，以及各区域之间如何联动。

## 1. 页面整体结构

页面由五个部分组成：

1. 顶部标题区：显示当前公元年份的制度快照、朝代、年号和当前视图统计。
2. 顶部功能区：切换“时序事件”“层级结构”“年表”三个视图。
3. 导航区：时序事件和年表使用左侧列表；层级结构使用可折叠的左侧“实体目录”。
4. 中央区域：显示事件卡片、全屏层级关系画布或实体年表。
5. 底部年表：统一控制全页面当前选中的快照年份。

底部快照年份是三个视图共享的。切换视图不会自动重置已经选择的年份。

## 2. 底部年表如何选择年代快照

底部年表覆盖公元 960—1279 年，包含年刻度、北宋/南宋分段、帝系、官制事件刻度和单年选择条。

### 点击某一年

- 点击或在选择条上拖动，都会定位到最接近的一年。
- 顶部显示“公元 XXXX 年制度快照”。
- 时间轴不再产生连续年份范围。

### 左右年份按钮

顶部时间标题两侧的按钮用于前后移动一年：

- 左侧按钮：快照年份向前移一年。
- 右侧按钮：快照年份向后移一年。
- 到达 960 或 1279 后不再继续扩展。

点击“取消选择”后，层级视图回到历时全貌。

### 官制事件刻度

底部“官制事件”一行每年对应一根刻度：

- 只统计有明确公元年的记录；
- 当年记录越多，刻度越长；
- 没有明确纪年的记录不会形成年度刻度。

### 时序事件视图的左侧排序

在“时序事件”视图中，左侧不会只保留当前时间段内的记录，而是保留符合机构/官职和事件类型筛选的全部精确纪年记录，再按与当前时间段的接近程度排序：

1. 当前时间段内的记录距离为 0，统一排在最前；
2. 时间段外的记录按距离当前范围最近的年数排列；
3. 距离相同时按事件实际时间先后排列；
4. 时间仍相同时保持稳定的记录顺序。

范围外的记录会显示“早 N 年”或“晚 N 年”。因此即使当前时间没有命中某条记录，仍然可以在左侧找到它，只是位置会靠后。

点击左侧事件只会把它移到中央阅读，不会改变底部时间。再次点击中央卡片才打开详细信息。底部时间改变后，左侧会自动滚动到新的区间内第一条记录，但已经放在中央的事件继续保留。

## 3. 进入层级结构视图

点击顶部“层级结构”后，页面显示：

- 占满主要空间的二维层级关系画布；
- 画布左侧可折叠的“实体目录”；
- 单击实体后停靠在画布右侧的实体详情（不遮挡画布）；
- 点击连线后停靠在画布右侧的关系证据（不遮挡画布）；
- “年代快照 / 历时全貌”切换；
- 机构、官职和三种主层级关系的图例。

顶部总统计中的“机构”和“官职”是全库实体总数，不随时间变化；“年代快照实体”统计快照年份中继承到的机构和官职。

层级工具栏另有两项结构统计：

- “有层级实体”：当前结构模式下至少参与一条层级关系的实体数；
- “无层级实体”：当前结构模式下没有参与层级关系的实体数。

这两项在“所选时段结构”中会随时间变化，在“历时全貌”中按完整历史关系计算。

中央层级画布显示三类关系：

| 关系 | 树中的方向和含义 |
| --- | --- |
| 上下级机构 | 上级机构 → 下级机构 |
| 编制隶属 | 机构 → 所属官职 |
| 统称与实例 | 统称 → 具体实例 |

“前后演变”不画进中央层级画布，但会出现在实体详情中。

## 4. 年代快照的显示逻辑

这是层级视图的默认模式。选择年份 `Y` 后：

- 每个实体取 `Y` 年以前最后一个有明确纪年的时间点，作为 `Y` 年状态；
- 该状态继承到下一时间点，不要求事件年份恰好等于 `Y`；
- 最后状态为罢废或合并时，实体退出快照；后续复置后重新进入；
- 早于第一个明确纪年时间点的年份不显示该实体；
- 年代未明记录不混入具体年份快照；
- 上下级机构以“下级机构截至 `Y` 年最近一次归属”为准；
- 编制隶属以“官职截至 `Y` 年最近一次归属”为准；
- 同一年多个时间点按月日、`prev_id/succ_id` 链和 ID 确定年末最后状态。

年份改变后，当前中心若已不存在于新快照，画布会清除该中心；其上级路径、下级节点和无层级分组均按新快照重建。

## 5. 历时全貌的显示逻辑

切换到“历时全貌”后：

- 三种层级关系不再受底部时间范围删减；
- 当前实体历来出现过的下级、属官和实例都可以显示；
- 历时模式下画布不标注关系时间；关系依据的年份或时间范围可从连线悬停提示、关系证据和实体详情中查看；
- 底部快照年份仍然保留，用于标记年代快照实体和左侧排序。

所以“历时全貌”只取消层级边的时间过滤，不会取消当前时间提示。

## 6. 实体目录如何分组

层级画布左侧常驻显示实体目录。点击目录与画布分界线中部的小箭头，可把目录收成一条窄边；再次点击箭头即可恢复。目录包含全部机构和官职，并分成上下两段。

目录展开或收起完成后，画布会按新的可用宽度重新计算缩放和居中位置。

### 上半部分

显示当前结构模式下至少参与一条层级关系的实体，包括：

- 作为上级的实体；
- 作为下级的实体；
- 作为机构与属官关系任一方的实体；
- 作为统称与实例关系任一方的实体。

### 分隔线以下

显示当前结构模式下没有参与层级关系的实体。

在“所选时段结构”中，这一分组会随底部时间变化；在“历时全貌”中，它按完整历史关系计算。

“当前时段无层级关系”不等于数据库里没有这个实体，也不等于它没有事件记录。

## 7. 实体目录的完整排序顺序

上半部分和分隔线以下分别独立排序，规则完全相同：

1. 当前底部时间段内有明确纪年记录的实体排在前面；
2. 同为活跃或同为不活跃时，全部历史记录数量较多的实体排在前面；
3. 记录数量相同时，按中文名称排序。

这意味着：

- 绿色圆点实体通常集中在每一段顶部；
- 切换底部时间后，实体可能在目录中重新排序；
- 切换到“历时全貌”后，关系分组按全历史计算，但排序第一优先级仍然是底部当前时段是否活跃；
- 当前树中心会保持选中样式，但不额外强制排到第一位。

## 8. 年代快照标记的判定

绿色圆点表示该实体进入当前年份的年末快照，不再表示“该年恰好发生了事件”。

以下情况需要区分：

- 有绿点：实体在该年以前已有明确纪年状态，且最后状态不是罢废/合并；
- 没有绿点：实体未进入该年快照，或当前正在显示历时全貌；
- 年代未明不会产生具体年份快照标记；
- 进入快照但没有当年层级关系的实体，可以出现在无层级分组中。

顶部“年代快照实体”统计与绿色圆点使用同一口径。

## 9. 实体目录的样式和操作

- 机构使用方形标记；
- 官职使用圆形标记；
- 当前画布中心保留机构或官职自身颜色，并使用强调边框；
- 从实体详情中的关系悬停联动到的实体使用强调色高亮；
- 无层级实体文字较淡；
- 目录的展开或收起由用户控制，选择实体后不会自动改变目录状态。

点击目录实体时：

- 如果它不是当前中心，它成为新的画布中心，画布重新排列下级结构并自动适应可见区域；
- 如果它已经是当前中心，不重新布局，只打开或关闭实体详情；
- 实体详情停靠在画布右侧，画布相应收窄并自动重新居中；
- 在层级视图中选中实体不会自动改变底部时间段。

最后一点很重要：层级视图以“当前时间看这个实体”为主，时间范围优先保持用户当前选择。

## 10. 中央层级画布的排列逻辑

中央区域只展开“当前中心实体及其向下关系”，不是把所有根节点同时画出来。中心实体位于上方，下级按层级向下排列，同级节点横向展开。

同一父节点下的子节点按以下顺序显示：

1. 上下级机构；
2. 编制隶属；
3. 统称与实例；
4. 同类关系中，记录较多的实体优先；
5. 记录数量相同时，按名称保持稳定顺序。

主层级按“父节点向下的竖线 → 一条横向总线 → 每个子节点独立向下的箭头”连接。同一父节点无论包含几种关系，都只使用一条总线；关系类型在总线分叉到具体子节点的位置用「颜色 + 类型图标」的圆形标记区分（建筑=上下级机构、人形=编制隶属、交叠方框=统称与实例），连线本身全为实线。图例固定在层级工具栏中，不占用画布空间。

一个实体在画布中只保留一个主要位置，其他上级通过节点左上角数字角标展开的关系卡查看，不在主树中重复生成节点或跨图连线。循环关系不会继续递归生成新节点。

具体操作：

- 单击节点：打开或关闭实体详情，不改变画布中心；
- 点击右侧实体详情中的“设为中心”：把当前详情实体设为新的画布中心，重新展开它的下级；
- 鼠标滚轮或右下角加减按钮：缩放画布；
- 拖动画布空白处：平移当前结构；
- 点击右下角重置图标：恢复自动居中和默认缩放；
- 节点默认整棵展开；聚焦模式下点击“余 N 项”翻页时，画布保持当前视口，被操作的节点锚在原地，新增下级就地出现；
- 重新设定中心或切换时间结构时，画布会重新计算边界并自动居中到完整可见的位置；
- 重新设定中心时，默认展开该中心下面的整棵树；
- 当前中心默认展示全部下级，不做分页。

## 11. 上级路径和多上级实体

层级画布上方显示当前中心实体的主要上级路径：

```text
上级机构 › 下级机构 › 当前实体
```

点击路径中的任意实体，会把它设为新的画布中心。

一个实体可能有多个上级。页面选择其中一条作为主树路径，其他上级不再使用跨越画布的辅助虚线。多上级实体的左上角固定显示数字角标（其他上级数量）：点击后在节点旁展开关系卡，列出上级名称、关系类型和依据时间；关系较多时先显示前六项，其余仍可从实体详情查看。点击某一行只强调当前实体与该上级，其他节点和主树连线暂时淡化。再次点击该行或空白处恢复普通显示，点击“中心”可把该上级设为新的画布中心。

主要路径只用于稳定浏览，不表示其他上级关系无效，也不表示它一定是历史上最重要的上级。

## 12. 节点和关系的视觉含义

### 实体节点

| 实体 | 外形和颜色 |
| --- | --- |
| 机构 | 棕褐色竖排窄卡片 |
| 官职 | 青绿色竖排窄卡片 |
| 当前中心 | 保留实体类型颜色，使用强调色加粗边框 |
| 当前详情实体 | 强调色外边框 |

### 关系提示

| 关系 | 颜色、实线和图标 |
| --- | --- |
| 上下级机构 | 深褐色实线，总线分叉处建筑图标 |
| 编制隶属 | 橙褐色实线，总线分叉处人形图标 |
| 统称与实例 | 灰褐色实线，总线分叉处交叠方框图标 |
| 其他上级 | 节点左上角数字角标与局部关系卡，不绘制跨图连线 |

节点旁还可能显示：

- 深度触限时提示“下级 N”。

主树不直接标注关系时间。主关系的年份、时间范围或“时间未明”，可从连线悬停提示、关系证据和实体详情中查看；其他上级的关系时间直接列在局部关系卡中。编制员额仍从连线提示、关系证据或实体详情查看。

## 13. 关系证据如何查看

点击父子节点之间的主层级连线，证据卡会**直接弹在被点连线的旁边**，该连线同时加粗高亮，一眼能看出证据属于哪一条边。证据卡跟随画布的缩放和平移，靠近屏幕边缘时自动换到另一侧或夹回屏幕内。

点击后显示：

- 关系双方；
- 关系类型；
- 关系有记录依据的一个或多个时期；
- 引用出处；
- 引文原文；
- 说明或考证备注。

同一条关系如果双方记录分别提供了不同年份，会按离散时期显示，例如“978年、1134年”，不会写成“978—1134年”。

同一对实体在多个时期有同类关系时，会合并在一个“证”入口中，再按最早有依据的时期排列各条关系和证据；完全没有年份的记录排在有年份记录之后。

再次点击同一连线、点击空白处或点击关闭按钮，可收起证据卡。画布结构变化时，已打开的证据会关闭。

## 14. 实体详情侧栏的显示逻辑

单击画布节点后，实体详情从画布右侧渐进展开；关闭时渐进收起，画布会随侧栏宽度平滑调整。详情标题栏中的“设为中心”是独立的聚焦操作；只有点击它才会重新以该实体展开层级树。详情显示：

- 实体名称、类型和有记录的时间范围；
- 官职性质、品级等属性；
- 与该实体有关的全部关系；
- 该实体的全部纪事和引用。

详情中的关系以当前实体为视角显示：

| 显示文字 | 含义 |
| --- | --- |
| 下级 / 上级 | 当前实体的下级或上级机构 |
| 属官 / 隶属于 | 当前机构的属官，或当前官职所属机构 |
| 实例 / 统称 | 当前统称的实例，或当前实例所属统称 |
| 后继为 / 前身为 | 当前实体的前后演变 |

实体详情显示完整历史关系，不受底部当前时间段限制。因此可能出现：

- 当前中央画布中没有的其他时期关系；
- 当前中心向上或其他路径中的关系；
- 不进入层级树的“前后演变”。

在事件详情中展开某条关系后，关系时间也使用同样的离散时期显示：

- 有一个时期时显示该年份或范围；
- 有多个不连续时期时逐段列出；
- 没有可用年份时显示“时间未明”；
- 不会用最早年份和最晚年份补成一段连续历史。

## 15. 实体详情中关系的悬停和点击联动

鼠标移到详情中某条关系上时：

- 如果关系另一方已经出现在画布中，对应节点会同步高亮；
- 如果它是当前主树关系，对应的具体分支线同步加粗；
- 如果它属于“其他上级”，右侧自动展开对应节点的关系卡并高亮准确的一行，不显示整组其他关系；
- 无论属于哪一种关系，都只保留关系两端和准确关系为高亮，其余节点与主树内容使用同一淡化程度；
- 如果实体目录正在打开，目录中的对应实体也会高亮。

以上都只是 hover 预览：鼠标移开右侧详情中的关系后立即恢复，不改变选中实体、不切换右侧详情，也不重排画布。

点击关系后：

- 关系另一方成为新的选中实体；
- 画布以它为新中心重新展开；
- 实体详情切换到该实体；
- 底部时间段保持不变。

## 16. 搜索与层级视图联动

层级视图中的顶部搜索按实体名称查找机构和官职。

点击搜索结果后：

- 关闭搜索结果；
- 对应实体成为画布中心；
- 画布默认展开它的下级并恢复自动居中；
- 打开右侧实体详情侧栏；
- 不自动修改底部快照年份。

如果搜索结果不在当前快照中，它不会被强行加入快照画布；可切换到“历时全貌”查看。

## 17. 底部时间变化对层级视图的完整影响

当用户点击/拖动到新年份，或用左右按钮前后移动一年后，层级视图依次发生以下变化：

1. 顶部公元时间、朝代和年号更新；
2. 每个实体重新选择截至该年的最后状态；
3. 上下级和编制关系重新选择最近一次归属；
4. 中央画布根据新快照重新生成并排列上下级结构；
5. 顶部主要上级路径可能变化；
6. 实体目录中有层级和无层级分组重新计算；
7. 快照标记和“年代快照实体”重新计算；
8. 实体目录的两个分组分别重新排序；
9. 当前中心若已不存在于新快照，则清除中心和详情。

在“历时全貌”中，画布不随快照年份删减关系。

## 18. “年表”视图与底部时间的联动

顶部“年表”是按实体查看完整时间记录的独立视图，但与同一个底部快照年份双向联动。

### 年表左侧实体如何排序

排序顺序为：

1. 当前已经选中的实体固定在最前；
2. 当前快照中能继承到状态的实体靠前；
3. 全部历史记录较多的实体靠前；
4. 最后按中文名称排序。

当前已选实体仍固定在左侧顶部。

### 点击年表左侧实体

点击一个实体后：

- 该实体成为当前年表对象；
- 原先打开的事件详情关闭；
- 底部快照年份保持不变；
- 左侧列表滚动到该实体；
- 中央区域显示它的全部精确纪年事件，并另外保留时间不明记录。

如果该实体没有任何可用公元年，底部时间保持原状。

### 点击年表中的事件

点击某条事件后：

- 底部时间跳到该事件的起始年，并显示该年快照；
- 事件卡片滚动到中央可见位置；
- 右侧打开该事件的详情和关系；
- 再次点击同一事件可关闭详情。

没有可用公元年的事件可以查看详情，但不会改变底部时间。

### 在年表视图中修改底部时间

手动改变底部时间后：

- 当前实体保持选中；
- 左侧每个实体是否进入当前快照重新计算，并据此重新排序；
- 当前实体仍固定在第一位；
- 中央年表标记该年继承到的最后状态记录；
- 当前打开的事件不再代表新快照状态时，事件详情自动关闭。

### 年表搜索和关系跳转

- 在年表视图点击搜索结果，会选中该实体，快照年份保持不变；
- 从事件详情点击关系，会跳到关系另一端的实体和事件，并把快照跳到目标事件的起始年；
- 播放年表时按时间顺序逐条选择精确纪年事件，底部时间会随当前播放事件移动。

## 19. 三个视图对时间的不同使用方式

| 操作或显示 | 时序事件 | 层级结构 | 年表 |
| --- | --- | --- | --- |
| 底部年份联动主要内容 | 显示各实体在该年继承到的状态 | 重建该年机构与编制快照 | 标记各实体在该年的状态记录 |
| 点击导航项是否改时间 | 点击事件不改时间，只移到中央 | 点击实体目录项不改时间 | 点击实体跳到完整时间范围 |
| 搜索结果是否改时间 | 跳到事件年份 | 不改时间 | 跳到实体完整时间范围 |
| 沿关系跳转是否改时间 | 跳到目标事件年份 | 不改时间 | 跳到目标事件时间范围 |
| 时间改变后当前对象 | 中央事件保留，左栏滚到区间内第一条 | 中心实体保留并重排画布 | 实体保留，事件不相交时关闭 |

## 20. 常见现象说明

### 为什么左侧顺序会随着时间变化？

因为当前时间段内有明确记录的实体优先；时间改变后，活跃实体集合也会改变。

### 为什么层级视图点击实体后，底部时间没有跳到实体全部年份？

这是当前设计：层级视图保留用户正在考察的历史时段，只更换观察对象。只有“年表”视图选择实体时，才自动跳到实体完整时间范围。

### 为什么一个没有绿点的实体仍在树中？

绿点只表示当前时段有明确纪年记录。该实体可能仍有跨年层级关系或时间未明关系。

### 为什么同一条关系显示两个相隔很远的年份，而不是一个连续范围？

这两个年份分别来自关系双方各自的记录，只能证明关系在这些时期有依据，不能证明中间所有年份都连续成立。

### 为什么有绿点的实体却在“无层级关系”分组？

它在当前时段有事件记录，但没有当前能够显示的上下级、编制隶属或统称实例关系。

### 为什么实体详情有关系，中央画布里没有？

可能是关系不在当前时间段，属于“前后演变”，位于当前中心的上级方向，或者处在另一条路径中。

### 为什么切换时间后画布变了，但实体详情没有完全变化？

中央画布显示当前时段结构；实体详情用于查看完整历史关系。

### 为什么“历时全貌”中仍然有绿色圆点和当前活跃统计？

历时全貌展示全部层级关系，但绿色圆点和活跃统计仍用于提示底部当前时间段内有明确记录的实体。
